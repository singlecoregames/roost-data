# Nestling

A small pixel platformer about a fledgling learning to fly. Built with Godot 4.

![hoatzin](assets/sprites/hoatzin.png)

| Folder | Contents |
|---|---|

| `assets/models/` | 3D props (glTF) |
| `docs/` | Design notes |

## Run

```bash
godot --path . --editor
```
